# CampusPilot

CampusPilot is a browser-based student planning assistant that helps students prioritize tasks and organize their available study time.

## Features

- Sample student tasks with deadlines and priorities
- Schedule generation based on urgency and available time
- Add, edit, and complete tasks
- Automatic schedule recalculation
- Browser localStorage persistence
- Responsive dashboard

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

## Run locally

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run `python -m http.server 5500`.
4. Open `http://localhost:5500` in your browser.

## Limitations

Scheduling is performed by local JavaScript rules. The application does not currently use a live AI API, backend, or actual Alexa+ integration.

## Project status

Built as a student planning assistant prototype for a hackathon.
